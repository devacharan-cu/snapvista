# SnapVista

SnapVista is an elegant image discovery app that lets users search and explore visual content from across the web. Built with clean, modern design principles, SnapVista presents a responsive grid of images that adapts beautifully to any screen size—from mobile to desktop. Simply enter a topic, hit search, and discover moments.

## Design Decisions

1. **Teal & Cyan Color Palette**: I chose a teal and cyan gradient accent instead of purple to create a fresh, modern aesthetic that feels contemporary and inviting. The dark/light theme support ensures usability in any lighting condition, with carefully selected contrasts that meet accessibility standards.

2. **Sticky Header with Suggestion Chips**: The header stays visible while scrolling, keeping the search functionality always accessible. Quick-pick category chips (Nature, Cities, Animals, Technology) provide one-click topic suggestions, reducing friction for users exploring without a specific search term in mind.

## Features

- ✨ Modern, responsive grid layout using CSS Grid
- 🌙 Light/dark theme toggle with persistent preference storage
- 🏷️ Quick-pick suggestion chips for instant topic search
- 🎨 Original teal/cyan color scheme
- 📱 Mobile-first responsive design
- ♿ Accessible form controls and semantic HTML
- 🧹 Clear button to reset search input
